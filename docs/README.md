# Engineering Documentation

This folder contains the engineering documentation for the tendon-driven robotic finger FEA investigation and redesign.

## Case Study

The project case study documents:

- Physical ABS failure at the TPU tendon-channel exit
- FEA model setup and boundary conditions
- Correlation between simulation and the observed failure location
- Baseline stress of 38–49 MPa in the physical breakage zone
- 0.3 mm radius geometry modification
- Reduced breakage-zone stress of 18–24 MPa
- Final engineering design recommendation
